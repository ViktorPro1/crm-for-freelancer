## Сторонні компоненти

Проєкт використовує відкриті бібліотеки. Вони лишаються під власними ліцензіями, які не змінюються
ліцензією цього проєкту. Версії дивись у `package.json` і `package-lock.json`.

| Компонент | Ліцензія |
|---|---|
| Next.js | MIT |
| React, React DOM | MIT |
| Tailwind CSS, @tailwindcss/turbopack | MIT |
| @neondatabase/serverless | MIT |
| @neondatabase/auth | Apache-2.0 |
| TypeScript | Apache-2.0 |
| ESLint, eslint-config-next | MIT |

Інші транзитивні залежності підтягує npm. Повний перелік і ліцензії є в `node_modules` кожного пакета
після `npm install`.
