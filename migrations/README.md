# Міграції бази даних

Кожен файл тут описує одну зміну бази (нова таблиця, нова колонка). Файли нумеровані
і застосовуються по порядку: `001_...`, `002_...` і так далі.

## Як застосувати

З кореня проєкту:

    npm run db:status    # показує, що вже застосовано, а що ні
    npm run db:migrate   # застосовує нові файли

Підключення береться з `.env.local` (змінна `DATABASE_URL`). Застосовані файли
запам'ятовуються в таблиці `schema_migrations`, тому повторний запуск нічого не ламає.
Кожен файл виконується цілком або не виконується взагалі.

## Як додати нову зміну

1. Створи наступний за номером файл, наприклад `005_назва.sql`.
2. Пиши так, щоб команду можна було повторити без шкоди: `CREATE TABLE IF NOT EXISTS`,
   `ADD COLUMN IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`.
3. Уже застосований файл не змінюй. Нова зміна це новий файл.
4. Одна команда закінчується крапкою з комою, а всередині текстових значень крапки з комою
   не ставимо. Коментарі лише повним рядком, що починається з `--`.
