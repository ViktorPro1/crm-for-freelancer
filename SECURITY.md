# Політика безпеки

## Як повідомити про вразливість

Якщо ви знайшли помилку, яка може зашкодити користувачам чи даним (доступ до чужих клієнтів,
обхід входу або схвалення, витік даних, обхід підписки), повідомте про це **приватно**.
Не створюйте публічне обговорення (issue) і не публікуйте деталі до виправлення.

Спосіб: [приватне повідомлення в GitHub Security Advisories](https://github.com/ViktorPro1/crm-for-freelancer/security/advisories/new).
Воно бачить лише власник репозиторію.

Допоможе, якщо вказати:
- що саме не так і де (адреса сторінки або назва файлу);
- кроки, як відтворити;
- що можна зробити через цю помилку.

## Що чекати у відповідь

Проєкт веде одна людина, тому терміни орієнтовні: підтвердження отримання зазвичай протягом кількох днів,
виправлення залежить від складності. Якщо мине тиждень без відповіді, повторіть повідомлення.

## Що входить у межі

- сайт https://freelancer-crm-ua.vercel.app та код цього репозиторію;
- вхід, схвалення заявок, підписка, ізоляція даних між користувачами.

## Що поза межами

- вразливості в сторонніх сервісах (Neon, Vercel, GitHub): повідомляйте їхнім власникам;
- атаки, що вимагають фізичного доступу до пристрою користувача;
- автоматичні сканування без підтвердженого впливу, спам, соціальна інженерія.

## Правила для дослідників

Не працюйте з даними інших людей, окрім мінімуму, потрібного для підтвердження помилки. Не порушуйте роботу сайту
(без навантажувальних атак). Тестуйте на власних облікових записах.

Також доступний файл [security.txt](https://freelancer-crm-ua.vercel.app/.well-known/security.txt).
